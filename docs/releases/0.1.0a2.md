# HYBRIDGE 0.1.0a2

First public release of HYBRIDGE (HYBRIdizable Discontinuous Galerkin
Environment), an early-alpha Python library of hybridizable discontinuous
Galerkin methods for CPUs and NVIDIA GPUs. It follows the private pre-release
`0.1.0a1` (2026-08-05), published under the name `hdgfem`.
The qualification record is in [`early_alpha.md`](early_alpha.md).

## Upgrading from `hdgfem` 0.1.0a1

- **Package name:** import `hybridge` instead of `hdgfem`, and install the
  `hybridge` distribution.
- **Environment variables:** settings are now `HYBRIDGE_*` (for example
  `HYBRIDGE_PRECISION` and `HYBRIDGE_HOST_THREADS`). For this release the
  `HDGFEM_*` names are still read, with a `DeprecationWarning`.
- **Mesh cache:** the local mesh cache moved to `.cache/hybridge/meshes`, so
  existing caches are rebuilt on first use.
- **Diffusion stabilization default:** `DiffusionReactionHDGSolver` and
  `solve_diffusion_reaction_hdg` now default to
  `stabilization="global_length"`, τ = κ/L_Ω with L_Ω = 2|Ω|/|∂Ω|, instead
  of `1.0`. Both give τ = 1 for κ = 1 on [-1, 1]²; pass `stabilization=1.` to
  reproduce `0.1.0a1` results.
- **Advection defaults:** raw-CUDA advection now defaults to the cooperative
  local LU (`raw_lu_mode=None` resolves to `coop` for fused and split3
  assembly). DG-field velocities default to conflict-averaged upwind
  stabilization; explicit policies still override.
- **Solve results:** device-resident advection results now carry `field` as a
  lazy device-backed `DGField` instead of `None`.

## New

- **Package layout:** organized by operator family, stage and backend
  (`runtime → core → linalg → hdg → {transport, mixed} → solvers → diagnostics
  → io`), with a layering test that forbids upward imports.
- **Advection-diffusion-reaction:** stationary ADR HDG solver with NumPy,
  Numba and raw-CUDA tensor assembly.
- **Raw-CUDA transport:** three-stage TSLE-BSR (split3) assembly, and
  `raw_local_assembly="auto"`, which selects split3 from degree 8 when its
  requirements hold.
- **Experimental:** tensorized TSLE assembly (cuTENSOR/cuBLAS contractions with
  cooperative, cuBLAS or MAGMA batched LU), not yet selectable from the solver
  options.
- **Diffusion:** the face-block hp-multigrid PCG solver (`fb-hp-mg-pcg`).
- **Time integration:** the SI-BDF3 guiding-center scheme.
- **Reusable solvers:** context managers, warm starts, results that own their
  arrays, and options implied by the selected solver or assembly.
- **Showcase:** the README GPU examples, recorded to completion, with a
  reproduction guide. The README plays both videos in place. The positive-density
  video uses the KKT positivity projection from the `positivity-kkt`
  development branch, which is not part of this release.
- **Postprocessing in the first example:** the README's first solve recovers the
  degree-`p+1` field and plots it beside the HDG solution and the exact
  solution. `plot_solution_comparison` gains `postprocessed=`, which draws the
  diffusion case runner's panels titled with their polynomial degrees;
  `show_error=False`, which leaves out that comparison's error panel; and
  `backend=` (`"auto"`, `"matplotlib"` or `"pyvista"`), where `"auto"` keeps
  Matplotlib for meshes of at most 130 triangles.
- **Figure themes:** `hybridge.io.figures.apply_figure_theme` recolors a
  Matplotlib figure's text and frames on a transparent background.
- **`projects/diocotron`:** the diocotron application project (DOLFINx, native
  HDG and FreeFEM implementations, studies), shipped in the repository outside
  the wheel.

## Fixed

- The Numba Cholesky helper now detects non-finite input under the fast-math
  flags that parallel ADR kernels impose on it. Before, NaN and Inf blocks
  could be reported as factored.
- Identity-keyed basis caches no longer return values for a recycled array id.
- The `gpu-smoke` release lane named two renamed tests and could not run. Lane
  targets are now checked by name.
- Raw-CUDA diffusion without `fb-hp-mg-pcg` defaults to CSR output, which
  repeated AMGX solves require.
- The README equations now render on GitHub: display math uses fenced
  ```` ```math ```` blocks, guarded by a docs test.

## Packaging and documentation

- BSD 3-Clause license, with authors listed in `AUTHORS.md`.
- `hybridge.__version__` reports the installed version.
- The fp32 AMGX checks skip when the installed PyAMGX is the FP64-only build.
- Machine-local artifacts and generated study data were removed from the
  tree. References to untracked local evidence are marked "local, untracked".
- No absolute or home-directory paths remain: documentation and recorded
  provenance use paths relative to the repository root or its parent
  directory, and placeholders such as `/path/to/cuda-13` for system installs.
- All Markdown links were checked: four stale local links and one dead external
  link were fixed.
- Showcase videos are no longer stored in the repository; the media folder keeps
  posters and records with the digests of the published videos.

## Known gaps

See the [known release gaps](early_alpha.md#known-release-gaps). They include
the AMGX teardown abort at interpreter exit in GPU test processes, the
separate FP32 PyAMGX binding, PETSc numerical parity outside the release
lanes, and the accuracy of the default diffusion stabilization on large
domains.
