- [`generalized_diocotron_benchmark_plan.tex`](generalized_diocotron_benchmark_plan.tex):
  *A Geometry-Dependent Generalization of the Diocotron Benchmark*. It proposes
  rebuilding the disk diocotron test on bounded, simply connected, noncircular
  domains for the guiding-center model:
  - torsion-function band initialization;
  - action-angle coordinates of the converged equilibrium stream function;
  - eigenmode growth-rate and disk-analogue response tests;
  - corner-aware references for divertor-like domains.
