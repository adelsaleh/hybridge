# Important interpretation:
# - PBICGSTAB is the preconditioned BiCGStab implementation in AMGX. BICGSTAB
#   ignores the configured preconditioner in this build.
# - GMRES uses DGKS reorthogonalization and reliable explicit residual checks.
#   It stays on scalar CSR: native block-GMRES failed the small-system regression.
# - The default search uses native AMGX Krylov solvers and preconditioners only.
#   Deferred custom-pattern, custom-ordering, block-normalization and external
#   outer-solver paths cannot run without the explicit --experimental flag.
# - Native multicolor ILU factorization supports 4x4 blocks only; ILU(1) uses
#   distance-two coloring and explicit color/diagonal reordering flags.
#   The full matK matrix has already hit this kernel's per-row shared-memory
#   limit, despite passing the small-system test. These failures are retained.
# - Natural-order cuSPARSE ILU(0) uses the existing opt-in AMGX backend. The
#   20x20 trial relies only on contiguous CSR regrouping, not a mesh/face model.
# - CSR, 4x4 and 20x20 storage represent the same equations. Groupings introducing
#   more than 25% stored padding are rejected. This is not HYBRIDGE geometric ASM.
# - W cycles, three pre/post smoothing sweeps and a larger dense coarse solve
#   make AMG more expensive than the first benchmark. Blocks use aggregation;
#   scalar CSR uses classical HMIS/D2 coarsening with strength threshold 0.1.
# - fgmres_inner* uses flexible outer GMRES around a 30- or 50-step inner Krylov
#   approximate inverse. fgmres_amg_f_krylov_csr uses Krylov smoothing in F cycles.
# - Native BINORMALIZATION / NBINORMALIZATION presets are probe-only: they failed
#   the physical-residual smoke checks with this build/backend combination and
#   are excluded from the default search. They remain explicitly selectable.
# - Equilibration solves (Dr A Dc)y = Dr b and recovers x = Dc y. Acceptance is
#   based solely on finite x and the original CPU FP64 ||Ax-b||/||b|| <= 1e-8.
# - Residual correction solves use the same factors/hierarchy and a fresh zero
#   vector. Original residuals and all inner statuses are recorded separately.
# - Timing separates preprocessing, upload, setup, inner GPU solves, RHS resets
#   and CPU validation. Ranking includes preprocessing + upload + setup + solves.
# - Candidate failures and 30-minute timeouts are isolated in child processes.
#   Nonfinite native iteration residuals stop the worker immediately at all verbosity levels.
# - Original first-sweep records are retained unchanged.
# - Custom experiments are deferred at the user's request; see
#   commands_experimental.txt only when that work is explicitly resumed.
